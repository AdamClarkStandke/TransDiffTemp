# Scratch LLMs 
This repo will detail different LLM models and methods that are in use today. Instead of using popular libraries to implement these models and methods I want this repo to contain code from papers and/or books that detail the implementation process from scratch. I will update this repo as I find more papers and/or books that implement many of today's LLM models and methods from scratch.
